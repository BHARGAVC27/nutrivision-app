# NutriVision app — merged source bundle (30 Oct 2026)

Version **1.1.0** (versionCode 2). This is the merged app: the screening pipeline plus **everything from
both versions**:

| From | Features |
|---|---|
| Screening app | photo or **Upload from gallery**, live photo checks, MUAC + WHO z-score, Refer / Not sure / Healthy |
| Diet plan | weight-adjusted daily plan (calories, protein, grams per food group, 0–5 scores, meals, tips) for every label; **Share this result** PDF with the diet pages; register export as PDF |
| Nutrition extension | optional **Diet** question; **Food plan** screen: CNNS deficiency risk + today's menu with local food names, filled with the child's own weight-adjusted amounts |
| Both | NutriVision name and icon, 5 languages (Hindi default), read-aloud, no internet permission |

`README.md` covers the pipeline in detail. `docs/NUTRITION_EXTENSION.md` is the food-menu design record.

## Set up on a new Windows laptop
1. Install **Node 20+**, **Android Studio** (SDK, NDK 27.1, **CMake 3.31.6** via `sdkmanager "cmake;3.31.6"`).
2. **Install a JDK 17 (e.g. Eclipse Temurin 17).** Gradle needs JDK 17–23; JDK 24+ (including Android
   Studio's newest bundled one) breaks the native build. On prebuild, `plugins/with-build-props.js` finds a
   JDK 17–23 by itself (JAVA_HOME, `~/.gradle/jdks`, `C:\Program Files\Eclipse Adoptium`, `...\Java`, …) and
   writes it into `android/gradle.properties`. If it picks the wrong one, set `NUTRIVISION_JDK` to the JDK
   folder and run prebuild again.
3. In this folder:
   ```
   npm ci
   npx expo prebuild --platform android
   ```
4. Debug build on a phone or emulator: `npx expo run:android`.
   Release APK for phones: `cd android` then `./gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a`
   (add `--max-workers=1` if clang crashes with "frontend command failed due to signal" — it runs out of memory;
   close the emulator while building). Use `x86_64` instead of `arm64-v8a` for the Android emulator.
5. Expo Go cannot run this app: the camera/MediaPipe part is a native module (`modules/nutrivision-vision`).

## Checks that need no device
```
npx expo start          (once, stop it with Ctrl+C — generates typed routes such as /food and /diet)
npx tsc --noEmit
npm run verify:pipeline   # phone pipeline = research pipeline, 65 children
npm run verify:diet       # diet plan port = Python, 16 cases + age sweep
npm run verify:nutrition  # deficiency risk + menu = Python, every age x sex x diet
```

## Not in this zip, on purpose
- `node_modules/`, `android/`, `.expo/` — regenerated by `npm ci` and `expo prebuild`.
- `releases/` — built APKs (ask for the final APK separately).
- `credentials/` — the release signing key is private. Without it, release builds are signed with the debug
  key and **cannot update a phone that has the official NutriVision APK** (uninstall it first; that deletes the
  screenings saved on that phone). `scripts/make-keystore.sh` makes your own key.

## Included
- `native-assets/` — the MediaPipe model files (`npm run fetch:models` can re-download them).
